# 五行程式碼重購 4.1.5 ~ 4.1.7

## 4.1.5 把程式碼移到類別中 push code into class
### sop
1. 把原涵式複製貼上到所有類別中.....
2. 把方法簽章複製到介面，並且換個名字
3. 遍覽所有類別中的新方法
    a. 將返回常數表示式之方法的結果直接內聯放入到呼叫的地方
    b. 把所有運算提前處理好
    c. 改為適當的名稱 
4. 把原來主體換為新方法呼叫

### EXAMPLE

- 紅綠燈
``` javascript
interface TrafficLight {
    isRed(): boolean;
    isYellow(): boolean; 
    isGreen(): boolean; 
     
 }
 
 class Red implements TrafficLight{
    isRed(){ return true; }
    isYellow(){ return false; }

    isGreen(){ return false; }
 }
 class Green implements TrafficLight{

 function updateCarForLight(current: TrafficLight){
```

## 4.1.6 將多餘的方法內聯到呼叫端

### SOP
1. 把方法改名
2. 複製本體
3. 貼到噴錯的地方

#### EXAMPLE
```javascript=
function handleInputs(){
    while (inputs.lenght > 0){
        let input = inputs.pop();
        handleInput(input);
    }
}
function handleInput(input: Input){

}
```

### 重構模式: 內聯方法 inline method
#### SOP
1. 換方法名稱
2. 複製本體
3. 放到報錯的地方
4. 編譯器沒報錯代表可以刪掉原來的方法

#### EXAMPLE

```javascript
function deposit (to: string, amount: number){
    let accountId = database.find(to);
    database.updateOne(accountId, { $inc:{ balance:amount }});
}
function transfer(from: string, to: string, amount: number){
    deposit(from, -number);
    deposit(to, number);
}
```
```javascript!

function transfer(from: string, to: string, amount: number) {
  let accountId = database.find(from);
  database.updateOne(accountId, { $inc: { balance: -amount } });
  let accountId = database.find(to);
  database.updateOne(accountId, { $inc: { balance: amount } });
}
```
