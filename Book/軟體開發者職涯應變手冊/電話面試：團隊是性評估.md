## 電話面試心流

----

### 暗中打探未來工作
- 先 google 蒐集資料( 產品表現,評價...)
- 目的是為了問更棒的問題

----

## 初步對頻
- 雙方能順利溝通嗎?
    - 通常面試官會先閒聊讓面試者進入狀況
- 再來一顆好球
    - 進入狀況後會根據履歷問問題
    - 目的是要溝通順暢

----

### 好球不再
- 來一題難題，讓面試者說故事
- 確保溝通順暢

----

### 換你提問
- 不問問題 = 告訴面試官我對職缺沒興趣
- 展現熱情

----

### 電話面試結束後
- 長時間尷尬停頓 ( 頻率不隊但還算安全 )
- 對立互動 ( 看是討論還是針鋒相對 )
- 感受
    - 所有人都可以被取代，但是如果你離開團隊會想念你嗎?
    - 30分鐘如果都沒找到溝通方式，未來是否能和團隊相處融洽

----

### 後續的步驟
- 如果主動談後續代表有機會
- 沒講要主動問，如果被打模糊仗代表不妙

----

# 緊張與不安

----

### 不安最大原因是被審判
- 被回顧所作所學的一切

----

### 問題類型
- 特定面向
- 解決問題面向
- 開放面向

----

### 回答問題的流程
- 先確認面試官想聽的 ( 釐清問題 )
- 一時想不到就把問題唸出來 ( 爭取思考時間 )
- 勇於承認沒想法

----

### 理解是自信的基礎
- 理解題目才知道如何回答
- 面試目標是擺脫緊張與不安

---

# 啟動對話「按鈕」
- 面試的目的是交換資訊

----

### 名為面試官的生物
- 理解面試流程
- 面試官涉及整個組織架構 => 新創
- 後續分為結構化和非結構化

----

### 結構化
- 每個人負責特定領域
### 非結構化
- 只安排時辰，內容隨興發揮


----

### 作者採用混和型
- 只給主題 or 面試官的技能樹

----

## 面試官分類

----

### 氣噗噗型
- 會跟你抱怨現況
- 最佳策略是多了解他所謂的現況
- 面試官影響力: 低 ( 通常在浪費時間 )

----

### 健談型
- 面試官影響力: 低
- 這類型面試官通常講話沒重點所以，回報面試結果很難說服雇主

----

### 狡猾型
- 中規中矩，清楚自己就是要問你問題，過程會透露對話按鈕
- 面試官影響力: 中
- 有獨特的面試匯報能力

----

### 刻意刁難型
- 各種刁鑽問題
- 大家要放輕鬆享受解謎的樂趣
- 面試官影響力: 低 or 中
- 精神霸凌者

----

### 陰險型
- 想找到對話按鈕會被反問
- 問他無法回答的問題打亂節奏
- 再問一個他回答的了的問題，就能開啟對話
- 面試官影響力: 中 ( 要了解非工程師的他來審查甚麼 )

----

### 沉默型
- 發問機器人
- 技術資深人員，展現技術就對了
- 面試官影響力: 高
- 如果是面試技術型職位那會生不如死

----

### 執行長型
- 流程中的最高主管
- 不必花心思找對話按鈕
- 試著推銷自己
- 面試官影響力: 極高
- 人事部門不會想跟頂頭上司意見相左

----

### 嶄新的視角
- 幾輪面試後會比他們更了解他們團體的健全程度
- 跟大量面試官交換過資訊

# 事業
- 可預期的關鍵時刻
- 出乎意料的關鍵時刻

----

### 你是一門專業
- 職崖中會有 5-10 份工作
- 職崖會需要評估一些指標

----

### 實際收入
- 底薪, 福利...都要算進去

----

### 估算薪資條件
- 對方知道你越需要這份工作，薪水會開越低

----

### 底薪
- 想辦法提高
- 打聽工作內容相同的人拿了多少
- 如果沒招就現職+10%

----

### 職稱
- 讓你的職崖看起來有積極發展

----

### 到職獎金
- 要想想公司提供這個是想掩蓋甚麼

----

### 股票分紅
- 很難估算
- 作者講了各種情況，重點就是要在有根據的情況下推測當作衡量指標

----

### 薪資協商角色
- 講到錢就會換個人來談
- 公司會有雇用標準

----

### 薪資權衡
- 第一次收到薪資條件，作者從來沒有滿意過

----

#### 底薪變低
- 在同產業，且發展成熟的公司，底薪不可能變低不然就是有問題

----

#### 底薪低沒關係，有獎金
- 鬼扯

----

#### 有一疊股票
- 都是推測，如果對公司股票評價很高可以考慮

----

### 最後通牒
- 要馬離開要馬談別的福利
    - 額外特休
    - 在家工作
    - 過幾個月後重新評估

----

### 拒絕然後轉身離開
- 記得要先道謝
- 要清楚知道自己為什麼拒絕
- 問自己熱愛這份工作的那些面向

----

### 更好, 更快還要更多
- 一切還是憑感覺
    - 對薪資, 同事, 產品, 公司走向
- 要能對任何人解釋為何去了新工作
